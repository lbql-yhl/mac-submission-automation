# UTM 飞书机器人

飞书机器人只负责登记、现有运行状态和卡片能力。技能执行命令以项目 `skills/<skill>/SKILL.md` 为准，不在本文重复脚本内容。

## 当前状态

- 提审启动入口禁用。
- 完整登记消息与 `/提审 开始` 静默返回。
- 不创建 run、VM 名称、prompt 或 runner。
- 普通 Codex 对话及已有运行的状态能力保留。

## 数据边界

- 提审数据通过飞书 Bot/OpenAPI 获取，不抓取飞书桌面应用。
- Notion 通过项目 API 读写。
- 敏感值不写入日志、卡片或公开输出。

## 故障卡

- 自动诊断、修复和独立复验穷尽后才允许发送。
- 决定为 `stop`、`manual_continue`、`retry_skill`。
- 重试必须重新运行当前技能唯一入口。
- 日报专用群不得接收故障卡、成功卡、测试消息或普通回复。

## 技能范围

每段可单独运行，每个技能可人工单独指定执行。四段顺序见 [project-workflow.md](project-workflow.md)。
